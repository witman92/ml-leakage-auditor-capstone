\textbf{Repositorio:} \url{https://github.com/witman92/ml-leakage-auditor-capstone}.

Todas las tablas y figuras de este informe se generan en \arch{04_experiments/results/} y se reproducen con:

\begin{footnotesize}
\begin{verbatim}
pip install -r requirements.txt
python 04_experiments/demo_fuga.py   # ejemplo visual (Fig. 1.2)
python ejecutar_todo.py          # 192 scripts, estadistica, figuras y 37 pruebas
streamlit run 06_web/app.py      # plataforma web
\end{verbatim}
\end{footnotesize}

La carpeta del proyecto se abre en VS Code con \arch{capstone.code-workspace}; cada paso del experimento tiene una tarea asociada. El detalle de decisiones y desviaciones está en \arch{07_informe/decision_log.md}.
